# Club42 Iscrizioni

Webapp statica responsive per gestire le iscrizioni agli eventi di Club42.

## Funzioni

- Creazione e modifica eventi
- Gestione capienza
- Iscritti confermati / lista d'attesa / annullati
- Stato pagamento
- Stato socio Club42
- Telefono, email, esigenze alimentari e note
- Ricerca e filtri
- Esportazione CSV
- Backup e ripristino JSON
- Salvataggio locale tramite `localStorage`

## Avvio

Aprire `index.html` in un browser oppure pubblicare il repository con GitHub Pages.

## GitHub Pages

Per pubblicare dal branch principale:

1. Aprire **Settings → Pages** nel repository.
2. In **Build and deployment**, scegliere **Deploy from a branch**.
3. Selezionare branch `main` e cartella `/ (root)`.
4. Salvare.

Il sito sarà normalmente disponibile su:

`https://ilboccia94.github.io/Club42-Iscrizioni/`

> Nota: la versione attuale usa dati locali nel browser. Per iscrizioni pubbliche condivise tra più utenti serve un backend/database condiviso.
